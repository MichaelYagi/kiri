Batch cropping

A recipe for stepping one shared Kiri instance through a queue of images — not a separate class, just plain Kiri plus a small amount of your own bookkeeping.

One DOM/stage instance is reused across images — not one instance per image — so every interaction you already know (drag, zoom, rotate, flip, filters) works exactly the same, with no separate API to learn. The only new pieces are the queue array, the current index, and where captured results get stored — all things a plain array already does well, so there's no dedicated class for it.

import { Kiri } from "@michaelyagi/kiri";

const items = [];   // { source, loadOptions? }
let index = -1;
const captures = [];

const cropper = new Kiri(container, options);

async function next() {
  if (index + 1 >= items.length) return false;
  index += 1;
  await cropper.load(items[index].source, items[index].loadOptions);
  return true;
}

async function previous() {
  if (index <= 0) return false;
  index -= 1;
  await cropper.load(items[index].source, items[index].loadOptions);
  return true;
}

async function capture(exportOptions) {
  const result = await cropper.export(exportOptions);
  captures[index] = result;
  return result;
}
items.push({ source: fileA }, { source: fileB });

while (await next()) {
  // cropper now shows items[index].source — let the user adjust it
  // (drag/zoom/rotate/whatever), then capture it:
  await capture();
}

captures; // all crops, in order
cropper.destroy();

Adding items later

You don't have to build the whole queue up front — it's just an array, so push to it whenever:

fileInput.addEventListener("change", () => {
  for (const file of fileInput.files) items.push({ source: file });
});

A typical UI loop

nextButton.addEventListener("click", async () => {
  const hasNext = await next();
  if (!hasNext) {
    showResults(captures);
    return;
  }
  statusEl.textContent = `Editing item ${items[index].source.name}`;
});

prevButton.addEventListener("click", () => previous());
captureButton.addEventListener("click", () => capture());

previous() mirrors next() — it steps cropper back one item and returns false (without moving) once index is already 0, so a "Back" button can disable itself the same way a "Next" button does at the end of the queue.
